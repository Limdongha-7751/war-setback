# 전쟁은 경제를 몇 년 전으로 되돌리나

개인 PRD 과제 · 남서울대학교 컴퓨터소프트웨어학과 임동하

- **웹 (직접 해보기):** https://limdongha-7751.github.io/war-setback/
- **우크라이나 2022 바로 보기:** https://limdongha-7751.github.io/war-setback/#UKR-2022
- **포스터 (A2):** [`poster/poster_final_light.pdf`](poster/poster_final_light.pdf)

## 문제
전쟁 피해는 보통 "GDP −22.7%"처럼 보도됩니다. 이 숫자로는 얼마나 잃었는지 체감하기 어렵고, 충격을 받은 나라 중 어디가 회복에 실패할지 미리 가릴 기준도 없습니다.

## 핵심 기능
1. **후퇴 연수:** 충격 후 1인당 실질 GDP 최저점이 "마지막으로 그만큼 낮았던 해"를 찾아, 충격 직전 해에서 몇 년 거슬러 올라갔는지 계산합니다.
2. **스카이라인 시각화와 분쟁 간 비교:** 연도별 건물 높이로 경제 규모를 보여 주고, 과거 개발도상국 분쟁 발발 35건 사이에서 해당 사례의 위치를 표시합니다.
3. **회복 실패 조기경보 검증:** 충격 3년 뒤 1인당 GDP가 충격 직전보다 낮은 경우를 "회복 실패"로 정의하고, 무엇으로 미리 가를 수 있는지 검증했습니다.

## 주요 결과
| 항목 | 결과 |
|---|---|
| 우크라이나 2022 (1인당) | 2003년 수준, **18년 후퇴** (2021년 대비 −22.7%) |
| 우크라이나 2022 (총량) | 2000년 수준, 21년 후퇴 (−28.8%) |
| 반등 후 (2023) | 여전히 2016년 수준, 2021년 기준 5년 뒤처짐 |
| 분쟁 발발 35건 | 후퇴 0년 43%, 중앙값 1년, 상위 25% 6년 이상, 최대 55년 |
| 회복 실패 예측 (AUC) | 올해 성장률 단순 규칙 0.768 > 로지스틱 0.743 ≈ 로지스틱+완충변수 0.744 > MLP 재설정 0.692 > MLP 기본 0.495 |
| 요인별 실패율 차이 | 국가 단위 부트스트랩 95% CI에서 유의한 것은 군사비(+13.9%p, [+2.5, +26.7])뿐 |

가설 H1(구조 변수 모델이 단순 규칙보다 낫다)과 H2(완충 변수가 예측을 개선한다)는 모두 기각되었습니다.

## 저장소 구조
```
index.html                         배포되는 웹 페이지 (web/build_index.py 로 생성)
web/template.html                  웹 페이지 원본 (데이터 자리: __DATA__)
web/build_index.py                 template + data → index.html
data/setback_data.json             210개국 1인당·총량 실질 GDP, 분쟁 발발 35건
analysis/war_setback_analysis.ipynb  데이터 수집·분석·검증 전체 (실행 결과 포함)
poster/make_poster.py              포스터 생성 스크립트 (light / dark)
poster/poster_final_*.pdf          제출한 A2 포스터
```

## 재현 방법
1. **분석:** `analysis/war_setback_analysis.ipynb`를 Google Colab에서 열고, Colab Secrets에 `KAGGLE_API_TOKEN`을 등록한 뒤 런타임 → 모두 실행. 마지막 셀이 `setback_data.json`을 내려받습니다.
2. **웹:** 내려받은 파일을 `data/`에 넣고 저장소 루트에서 `python web/build_index.py`.
3. **포스터:** `cd poster && python make_poster.py light` (Noto Sans CJK 폰트 경로는 Linux 기준이라 환경에 맞게 수정 필요).

## 한계
- 모든 결과는 관측된 연관성이며 인과 효과가 아닙니다. 군사비·원조는 역인과 가능성이 큽니다.
- 전쟁 중 통계가 끊긴 나라·연도는 빠지므로 가장 심한 피해가 과소추정될 수 있습니다.
- 우크라이나는 2014년 이후 통계 범위(크림·돈바스 일부 제외)가 바뀌었습니다.
- 회복 실패 예측에서 성장률 규칙이 이긴 데에는 충격 해 성장률이 3년 뒤 GDP 경로에 일부 포함된다는 기계적 관계도 작용합니다.
- 연 단위 자료라 "조기경보"도 실제로는 성장률 공식 발표 이후(약 1년 뒤)에만 쓸 수 있습니다.

## 출처와 기여
- 노트북의 Model 1(다음 해 경제구조 예측 MLP)은 팀 프로젝트 당시 홍태겸이 작성한 코드입니다. 검증 결과 6개 변수 모두 "올해 값을 그대로 쓰는" 기준보다 오차가 컸고, 이 비교를 노트북에 함께 남겼습니다.
- 데이터 수집·전처리, 회복력 분석, 후퇴 연수·조기경보·강건성 검증, 웹, 포스터는 임동하 작성입니다.
- 코드 작성과 포스터·웹 제작 과정에서 생성형 AI(Claude)의 도움을 받았습니다.
